# ADR 0003: Сохранить одобренный demo UI

- Статус: принято
- Дата: 2026-08-14

## Решение

Исходный commit помечен тегом `demo-approved`. Production foundation добавляется инкрементально; визуальный интерфейс и demo-flow не переписываются без продуктовой причины.

## Последствия

Некоторые mock-вызовы пока остаются внутри `SurveyApp` и явно не являются production boundary. Их перенос на server use cases выполняется на следующем согласованном этапе.
